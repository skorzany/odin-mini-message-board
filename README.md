# odin-mini-message-board

A simple message board project made in Express and EJS for The Odin Project.<br/>
No database, it is mimicked by a simple array of objects defined inside the router.<br/>
Views all messages by default, allows for adding new one via a special form,<br/>
as well as viewing each message's details.<br/>
Contains partial views for header and footer as well as templates for main content of each page.<br/>
Added a custom error for bad URL's.<br/>
Project automatically deployed and hosted on [Render.com](https://render.com/).<br/>
You can see it live in action at [this link](https://odin-mini-message-board-3h6y.onrender.com/).

It was a nice hands-on practice working with the backend.<br/>
I hope that you like it!
